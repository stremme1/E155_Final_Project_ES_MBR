# Files Needed for Testing

## ✅ Required Source Files (for Synthesis/Implementation)

### 1. Top Module
- **`drum_system_top.sv`** - Main top-level module
  - Instantiates I2C IP block (`i2c_block`)
  - Contains clock generation, debouncing, I2C controller, gesture recognition

### 2. I2C Controller
- **`bno055_i2c_controller_gyro_only.sv`** - I2C controller for BNO055
  - Reads gyroscope data (X, Y, Z) from BNO055 via System Bus
  - Inlined System Bus master

### 3. Gesture Recognition
- **`gesture_recognition_gyro_only.sv`** - Gesture recognition logic
  - Uses only gyroscope Y and Z data
  - Detects drum gestures and outputs sound IDs

### 4. I2C IP Block (Generated by Module Generator)
- **`i2c_block.v`** - **CRITICAL: Must be generated and added to project!**
  - Generated by Lattice Radiant Module Generator
  - Must have I2C1 enabled, I2C2 disabled
  - Must be added to Radiant project as source file

## ✅ Test Bench Files (for Simulation)

### 1. Main Test Bench
- **`drum_system_top_gyro_tb.sv`** - Test bench for gyro-only design
  - Tests system initialization
  - Tests button functionality
  - Tests gyro trigger detection
  - Tests sound ID generation

## 🔧 How to Test

### Simulation Test (iVerilog):
```bash
cd E155_FPGA_MCU_DrumSet/fpga/verilog
iverilog -g2012 -DSIMULATION -o test_gyro drum_system_top_gyro_tb.sv drum_system_top.sv bno055_i2c_controller_gyro_only.sv gesture_recognition_gyro_only.sv
vvp test_gyro
```

### Synthesis Test (Lattice Radiant):
1. Create new project for iCE40UP5K
2. Add source files:
   - `drum_system_top.sv`
   - `bno055_i2c_controller_gyro_only.sv`
   - `gesture_recognition_gyro_only.sv`
   - **`i2c_block.v`** (generated IP - CRITICAL!)
3. Run synthesis
4. Check resource usage report

## ⚠️ Critical Notes

1. **I2C IP Block (`i2c_block.v`)**:
   - Must be generated using Module Generator
   - Must have I2C1 enabled, I2C2 disabled
   - Must be added to Radiant project as source file
   - If missing, synthesis will fail or create stub

2. **Module Name**:
   - I2C IP module name: **`i2c_block`** ✅
   - Instantiated in top module as: `i2c_block i2c1_ip`

3. **Test Bench**:
   - Uses `define SIMULATION` for clock selection
   - Mocks I2C IP System Bus responses
   - Does NOT require actual I2C IP file for simulation
