# SPI Communication Test Module

This module is a simplified test harness for the BNO085 SPI communication.
It isolates the `bno085_controller` and `spi_master` from the rest of the drum set logic to allow for focused debugging.

## Contents

- `spi_test_top.sv`: Top-level module for the test.
- `bno085_controller.sv`: The SPI controller logic (copied from parent).
- `spi_master.sv`: The low-level SPI driver (copied from parent).
- `tb_spi_test.sv`: Testbench for validating the controller logic.
- `mock_bno085.sv`: Simulation model of the BNO085 sensor (validates SHTP protocol).
- `hsosc_mock.sv`: Mock internal oscillator for simulation.
- `constraints.pdc`: Pin assignments for Lattice Radiant.
- `constraints.pcf`: Pin assignments for open-source flow.

## Usage

1.  **Create a new Radiant Project** (or use your existing one).
2.  **Add Files**: Add `spi_test_top.sv`, `bno085_controller.sv`, and `spi_master.sv` to the project.
3.  **Set Top Module**: Set `spi_test_top` as the top-level module.
4.  **Import Constraints**: Add `constraints.pdc` to the project.
5.  **Synthesize and Program**: Build the bitstream and program your FPGA.

## Simulation

To run the simulation (requires Icarus Verilog):

```bash
cd E155_FPGA_MCU_DrumSet/fpga/spi_test_module
iverilog -g2012 -o tb_spi_test.vvp tb_spi_test.sv spi_test_top.sv bno085_controller.sv spi_master.sv mock_bno085.sv hsosc_mock.sv
vvp tb_spi_test.vvp
```

**Note**: The VCD file (`spi_test.vcd`) generated by simulation can be very large and should not be committed to git.

## LED Status Indicators

- **Blue LED (Heartbeat)**: Blinks ~1Hz. Indicates the FPGA clock is running.
- **P28 (Initialized)**: Turns ON when the BNO085 is successfully initialized.
- **P38 (Error)**: Turns ON if an error occurs (e.g., stuck INT pin).
