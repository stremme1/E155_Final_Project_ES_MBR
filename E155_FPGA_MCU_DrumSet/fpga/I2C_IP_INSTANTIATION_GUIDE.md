# CRITICAL: I2C IP Instantiation Guide

## The Problem

Your `drum_system_top.sv` exposes System Bus ports but **DOES NOT INSTANTIATE the I2C IP wrapper** generated by Module Generator. This means:

1. **System Bus signals are floating** - not connected to I2C Hard IP
2. **I2C IP wrapper is not included** - but synthesis might be trying to infer it
3. **Design won't work** - I2C communication impossible

## The Solution

You **MUST** instantiate the I2C IP wrapper in your top module.

### Step 1: Find Your Generated I2C IP Module

1. Look in your Radiant project for files generated by Module Generator
2. Find the I2C wrapper file (usually `i2c_master_top.v` or similar)
3. Note the **exact module name** and **port names**

### Step 2: Add I2C Physical Pins to Top Module

Your top module needs I2C physical pins:

```systemverilog
module drum_system_top (
    // ... existing ports ...
    inout  logic        i2c1_scl,  // I2C1 SCL (physical pin)
    inout  logic        i2c1_sda   // I2C1 SDA (physical pin)
);
```

### Step 3: Instantiate I2C IP Wrapper

Add this inside your `drum_system_top` module (replace module name with yours):

```systemverilog
// Instantiate I2C1 IP wrapper (generated by Module Generator)
// REPLACE "i2c_master_top" with your actual module name!
i2c_master_top i2c1_ip (
    // System Bus Clock
    .SBCLKi(i2c1_sb_clk),
    
    // System Bus Interface
    .SBWRi(i2c1_sb_wr),
    .SBSTBi(i2c1_sb_stb),
    .SBADRi(i2c1_sb_addr),
    .SBDATi(i2c1_sb_data_i),
    .SBDATo(i2c1_sb_data_o),
    .SBACKo(i2c1_sb_ack),
    .I2CPIRQ(i2c1_irq),
    
    // IP Configuration
    .IPLOAD(i2c1_ipload),
    .IPDONE(i2c1_ipdone),
    
    // I2C Physical Pins
    .I2C1_SCL(i2c1_scl),  // Check generated IP for exact port name
    .I2C1_SDA(i2c1_sda)   // Check generated IP for exact port name
);
```

### Step 4: Remove Temporary Assignments

Remove these temporary assignments from `drum_system_top.sv`:
```systemverilog
// REMOVE THESE - they're just placeholders
assign i2c1_sb_wr = 0;
assign i2c1_sb_stb = 0;
// ... etc
```

## Why This Matters for Resource Usage

The I2C Soft IP wrapper can consume **2000-4000+ LUTs** if:
- FIFO mode is enabled
- Multiple interrupts are enabled
- General call is enabled
- Wake-up logic is enabled

**To minimize I2C IP size:**
1. ✅ **Disable FIFO mode** (use register mode only)
2. ✅ **Enable only TX/RX Ready interrupt** (disable all others)
3. ✅ **Disable General Call**
4. ✅ **Disable Wake-up**
5. ✅ **Use minimal configuration**

## Expected Resource Usage

### With Minimal I2C IP Configuration:
- I2C Soft IP Wrapper: **500-1000 LUTs** ✅
- Our minimal design: **270-500 LUTs**
- **Total: 770-1500 LUTs** (should fit easily)

### With Full I2C IP Features:
- I2C Soft IP Wrapper: **2000-4000 LUTs** ⚠️
- Our minimal design: **270-500 LUTs**
- **Total: 2270-4500 LUTs** (might not fit)

## Verification Steps

1. **Check Module Generator Settings**:
   - Open Module Generator
   - Verify I2C configuration is minimal
   - Regenerate IP if needed

2. **Check Generated IP File**:
   - Open the generated `.v` or `.sv` file
   - Note the module name
   - Note all port names
   - Check for any large state machines

3. **Synthesize I2C IP Alone**:
   - Create a test project with just the I2C IP
   - Synthesize it
   - Check resource usage in Design Summary
   - This tells you the actual I2C IP size

4. **Update Top Module**:
   - Add I2C physical pins
   - Instantiate I2C IP wrapper
   - Connect all signals correctly
   - Remove temporary assignments

## Common Issues

### Issue 1: Module Name Mismatch
**Error**: Module not found
**Fix**: Check generated IP file for exact module name

### Issue 2: Port Name Mismatch  
**Error**: Port not found
**Fix**: Check generated IP file for exact port names (may differ from examples)

### Issue 3: I2C Pins Not Assigned
**Error**: Physical pins not connected
**Fix**: Add I2C physical pins to top module and assign them in Pin Assignment Editor

### Issue 4: IP Still Too Large
**Solution**: 
- Regenerate IP with minimal features
- Disable FIFO mode
- Disable all optional interrupts
- Use register mode only
